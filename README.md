# LinkPulse

> A distributed URL shortener with real-time click analytics, built to
> demonstrate production-style microservice architecture.

**Status:** 🚧 In development (Day 1: repo setup)

## Tech stack

| Area | Technology |
|---|---|
| Backend | Java 25, Spring Boot 4, Spring Cloud |
| Messaging | Apache Kafka |
| Cache | Redis |
| Database | PostgreSQL |
| Auth | Keycloak (OAuth2 / OIDC) |
| Frontend | Next.js, TypeScript |
| Observability | OpenTelemetry, Grafana |
| Deployment | Docker, Kubernetes |
